# Summary
A silly game made in Godot.
I made this project to learn some fundamentals of Godot,
and to learn some art in the process.

# Software
- Krita 5.3.3
- Godot 4.7.2

# Gameplay
You play as a bird-like creature, in an antarctic wasteland.
You must try to survive as you fly from isle to isle.
Get points as you fly.
Try to keep out of the water.
