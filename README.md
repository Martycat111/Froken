# Summary
A silly game made in Godot.  
I made this project to learn some fundamentals of Godot,  
and to learn some art in the process.  

This only for now, don't expect (or even hope for) rapid development.  
No dependencies, just unzip then run the main executable.  
Thanks for trying out my game!  

# Quick-Play:
To play as quick as possible,  
head on down to the "Cool buttons" section,  
and hit "Play Online".  
Be sure to check out the tutorial first, and foremost.

# Software
- Krita 5.3.3
- Godot 4.7.2

# Gameplay
You play as a bird-like creature, in an antarctic wasteland.
You must try to survive as you fly from isle to isle.
Get points as you fly, and try to keep out of the water.
